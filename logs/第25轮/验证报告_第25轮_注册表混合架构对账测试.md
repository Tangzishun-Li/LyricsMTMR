## 三、对账机制设计与覆盖论证

### 3.1 机制：测试侧唯一基准「规范清单」

`MTMRTests/RegistryReconciliationTests.swift` 持有一份规范清单 `canonicalItems`（98 条 × {name, 最小合法 JSON, identifierBase 期望值}）+ 16 个注册表专属键。清单由 `generate_registry_test.py` 直接从 `ItemsParsing.swift`（ItemTypeRaw case 名）与 `TouchBarController.swift`（identifierBase 映射）逐条提取生成——初始状态即与源码一致，此后任何漂移都会造成断言失败。重新生成脚本保留在仓库根（`generate_registry_test.py`），供后续轮次刷新清单。

### 3.3 覆盖完整性论证（switch 不可反射的替代取证）

Swift 无法反射 switch 分支，覆盖边界按如下三重取证闭合：

1. **编译期穷尽性**：decode / identifierBase / BarItemFactory 三处 switch 对 `ItemTypeRaw` / `ItemType` 均为穷尽匹配——给枚举**新增** case 而漏改任一 switch 直接编译失败（Xcode 报「switch must be exhaustive」）。因此「新增漏注册」的最短路径已被编译器拦截，测试兜底的是其余方向。
2. **运行时全量行为取证**（本测试）：穷尽性不覆盖「删 case」「改名」「映射错位」「注册表漏登」——这些编译期无感。L1 用 CaseIterable 枚举全集锁定删/改；L2 用 98 条最小 JSON 全量解码 + 逐条 identifierBase 期望值锁定 decode↔identifierBase 两处映射错位（98 个 identifierBase 期望值互异，名字↔case 映射被完全钉死）；L4 全量真实构造锁定工厂侧；L5 键集精确相等锁定注册表侧。
3. **行为等价性**：工厂全量构造直接复用生产路径（与第 23 轮 A 卡 controller 侧 guard 经代码审查 + item 级等价测试覆盖的先例一致）；不存在虚构断言——每条断言都有可执行的输入与可观测的失败。

## 六、等价性说明

- 测试全部走生产解析路径（`BarItemDefinition` ← `SupportedTypesHolder.lookup` ← `ItemType(from:)`）与生产创建路径（`BarItemFactory.createItem`），非自建平行实现。
- `canonicalItems` 清单初始值由生成脚本从源码提取（非手抄），因此「清单 vs 源码」的初始一致性有生成过程保证；之后任何漂移由断言捕获。
- noiseMeter 一条构造走「全局隐藏态」包装：`TouchBarVisibilityState.shared.setBarHidden(true)` + defer 恢复，利用 round-24 采集暂停门让 init 跳过真实 AVAudioEngine/TCC 路径；该包装只改变构造时的外部环境，不改变被测工厂代码。

## 七、风险点

1. **清单维护成本**：新增 widget 类型时须同步 6 处注册点 + 重新生成清单（`python3 generate_registry_test.py`）。清单与源码初始一致的保证依赖生成脚本而非手工；脚本本身在仓库根，若被删除需按 §二 表格人工重建。
2. **最小 JSON 的字段漂移**：若某类型 decode 分支新增**必填**字段（`decode` 而非 `decodeIfPresent`），L2 会立即失败（清单 JSON 缺字段）——这是有意的失效方向，但修法须同时更新清单 JSON 与生成脚本的 `REQUIRED_FIELDS` 表。
3. **identifierBase 期望值硬编码**：pomodoro/network/darkMode 三处的期望值以字面量写入清单（取自 `PomodoroBarItem.identifier` 等常量当前值）。若常量改名，L2 失败属预期（促发有意识更新）；若只改常量不改映射，测试不受影响（映射仍返回常量）。
4. **注册表全局单例**：`SupportedTypesHolder.sharedInstance` 为全局态，其他测试若向注册表注册新键会使 L5 精确键集断言失败；当前全库仅 `TouchBarController.init` 3 处注册（grep 实证），风险可控，新增注册点需同步更新清单 16 键。
5. **全量构造的资源副作用**：98 个 widget 真实构造会短暂启动各自定时器/一次性异步任务（与 WidgetLeakTests/CurrencyBarItem 先例同款）；已避免真实麦克风（noiseMeter 隐藏态）与真实脚本执行（source 为空）。
