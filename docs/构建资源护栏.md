# 构建资源护栏（r62-b 交付物）

> 一切 xcodebuild 必须经本锁脚本。这是轨道 R62 的结构性铁律（轨道文本 §7），
> 不是建议，不是风格偏好——它直接对应 2026-08-24 夜的 P0 故障根因。

## worker 用法

把原本直接执行的构建命令原样交给 `sh scripts/build-with-lock.sh`，其余不变：

```bash
cd LyricsMTMR && sh ../scripts/build-with-lock.sh xcodebuild \
    -project LyricsMTMR.xcodeproj -scheme MTMR \
    -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

- 全机互斥：锁文件默认 `/tmp/lyricsmtmr-build.lock`，同一时刻只放行一个经本脚本的
  构建；别的 worker 正在构建时，你的进程原地等待并收到 stderr 等待提示（首次发现被占
  立即打一行，其后每 30s 一行），拿到锁后自动开始。
- 对 xcodebuild 自动注入 `-jobs ${MTMR_BUILD_JOBS:-4}` 与
  `COMPILER_INDEX_STORE_ENABLE=NO`（原命令已含则不重复加），压低单次构建的内存峰值；
  非 xcodebuild 命令原样透传不注入。
- 退出码透传：脚本退出码 = 构建命令退出码，worker 判定成功失败照旧。
- 环境变量：`MTMR_BUILD_LOCK` 换锁路径（一般不用动）；`MTMR_BUILD_JOBS` 调并行度。
- 无参调用打印用法并以非 0 退出。

## 为什么必须这样（引轨道 R62 §1 取证链）

2026-08-24 夜用户报「现在一开这个软件就会卡死」。父卡通宵取证七条，结论：

**不是 R57–R60 减脂代码回归。App 二进制本体健康；「一开就卡死」是看板多 worker 并发跑
xcodebuild test 把 8GB 内存挤爆 → 系统级换页风暴 → 前台 app 被拖成假死。**

证据链摘要（完整表格见 docs/轨道文本_R62_启动韧性与构建资源护栏.md §1）：

| # | 证据 | 结果 |
|---|------|------|
| E1 | 用户实际运行的二进制 = DerivedData Debug 产物（tccd 日志 binary_path 证实） | 定位确切产物 |
| E2 | 父卡亲自 open 同一二进制并 sample 5s | 主线程安睡事件循环，CPU 0.1%，RSS 65MB，完全健康 |
| E3 | live items.json 注释感知解析 | 0 个 appleScriptTitledButton 轮询脚本，减脂轮未引入启动期脚本执行 |
| E4 | 8-23 唯一一份 .ips | XCTest 测试宿主 SIGABRT（CI 场景），排除 |
| E5 | 系统 log 两次手动启动 | 正常走完启动序列、存活约 2 分钟后体面退出——是假死不是崩溃 |
| E6 | 内存现场：free pages ≈110MB；swap used **6.1GB/7GB**（8GB M1） | 系统处于换页地狱 |
| E7 | 同时刻三 worker 在飞、ps 见 xcodebuild test 正跑 | 内存挤压的直接来源 |

E6+E7 即因果闭合：并发构建挤爆内存 → 换页风暴 → 前台假死。

所以结构性修复 = **全机串行构建锁：并行的是开发，串行的是构建**（§7 铁律）。
分析/文档/调研类工作照常并行不受限；一切重型构建排队过闸，机器上任何时刻最多一个
xcodebuild 在飞，内存峰值不再叠加。

## 实现说明（锁为什么可信）

- macOS 不自带 `flock(1)` 二进制。`flock(2)` 锁属于「文件描述 + 进程」，持锁进程
  退出即自动释放，因此脚本用一个后台 perl 进程做锁持有者：对锁文件加
  `LOCK_EX|LOCK_NB`，成功后写 ready 标记并每 0.5s 探测父进程 pid——父进程存活期间
  持续持锁；父 shell 死亡（含被 SIGKILL，无需 trap）holder 自行退出放锁。
  等锁方以 0.2s 粒度探测标记/持有者死亡并重试。全程内核级独占锁，无陈锁残留问题。
- 等锁提示：首次发现被占立即打一行 stderr，其后每 30s 一行；拿到锁打印获得锁的 pid
  与 `-jobs` 并行度。
- bash 3.2 兼容：不用关联数组、不用 `local` 等 bashism；`set -u` 下变量一律 `${}`
  包裹。
- 本脚本是 r62-b 卡交付物，接口契约见轨道文本 §4.2；后续轮次一切构建入口收口于此。
