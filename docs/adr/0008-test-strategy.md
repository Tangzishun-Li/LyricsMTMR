# ADR 0008：测试策略：策略枚举 + 契约 + GUI 护栏

- 状态：已采纳
- 日期：2026-11-16

## 背景

700+ 测试全是纯逻辑/契约，抓不到"能编译但启动即崩"和界面回归；同时这些测试也解释不了"为什么这样设计"。

## 决策

三层：① 决策逻辑抽纯函数枚举（PresentationPolicy 等）+ 契约测试；② 许可/计数/配置类用"防漂移"契约测试；③ GUI 用启动冒烟 + 三张快照做护栏，失败上传 diff artifacts。

## 取舍

快照对渲染环境敏感，需要阈值与人工确认；换来"启动即崩/界面走样"能在 CI 变红。

## 后果

故意破坏 golden 时 meanΔ=0.1458 判红，恢复后通过。

## 证据

`StartupSmokeTests`、`SnapshotTests`、`build-test.yml` 的 gui-smoke job。
