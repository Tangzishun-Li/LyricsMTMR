# 更新渠道：stable 与 beta

> 计划板第 19 条。目标：预览版只发给主动加入的人，稳定版用户永远收不到 preview。

## 机制

| 环节 | 行为 |
| --- | --- |
| 打 tag | `v0.4.0` → 正式版；`v0.4.0-preview` / `-beta` → 预览版 |
| appcast | 预览版条目带 `<sparkle:channel>beta</sparkle:channel>` 与 `<sparkle:prerelease/>` |
| 客户端 | 设置 → 关于 →「加入预览版」写入 `com.lyricsmtmr.update.channel=beta`；`SPUUpdaterDelegate.allowedChannels` 只在开启时返回 `{"beta"}` |
| 校验 | `publish.yml` 生成条目后由 `verify_release.py` 断言「tag 后缀 ↔ channel」一致 |

## 回到稳定版

Sparkle 不会自动降级。关闭「加入预览版」后：

1. 打开 [Releases](https://github.com/Tangzishun-Li/LyricsMTMR/releases)，下载最新的**不带 `-preview`** 的 DMG；
2. 拖进「应用程序」覆盖安装；
3. 之后只会在下一个正式版发布时收到更新。

## 已知限制

- 正式版发布前，latest 仍指向上一个正式版；beta 用户看到的"最新"也是两者中版本号更高的那个（Sparkle 按 build 号比较）。
- 没有灰度百分比；beta 渠道是全量预览。
