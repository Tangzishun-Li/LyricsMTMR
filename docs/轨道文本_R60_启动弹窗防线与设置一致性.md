## §4 API 契约（字段级冻结，并行实现不打架）

### 4.1 AppleScriptTCCGuard（r60-a 新建，供 ItemsParsing/AppleScriptTouchBarItem 调用）
```swift
enum AppleScriptTCCGuard {
    /// 脚本源是否引用了外部应用（启发式：匹配 tell application "X" 且 X ∉ {本进程}）
    static func referencedExternalApps(source: String) -> Set<String>
    /// 是否允许启动期自动执行：引用外部应用的脚本在首次自动执行前必须等一次显式点按。
    /// 返回 .allowed 或 .deferredUntilTap(apps:)
    static func startupPolicy(for source: String) -> StartupPolicy
}
```
行为契约：deferred 时 item 显示占位标题「▶」（title 语义，非 alert），用户点按后放行后续自循环。
MusicBarItem 不走此守卫（其 SBApplication 调用自带 isRunning 守卫且有专用权限面，本轮不动其脚本路径）。

### 4.2 MusicSourceRow 安装态徽标（r60-a，LyricsTabView 内既有行的视觉增强）
`NSWorkspace.shared.urlForApplication(withBundleIdentifier:) == nil` → 行尾加「未安装」灰字徽标，
开关仍可操作（预装后即生效），不做禁用。

### 4.3 SettingsRefreshAdvisor（r60-c 新建）
```swift
enum SettingsRefreshAdvisor {
    /// tab 保存设置后调用。能安全热更新的域直接触发 reloadStandardConfig（内部去抖 ≥0.5s 合窗），
    /// 不能安全热更新的域返回 false 并由调用方展示 Banner。
    @discardableResult static func notifyChange(domain: String) -> Bool
    /// 需手动刷新时展示的横幅文案（中英双语，localized 现有机制）
    static var bannerText: (zh: String, en: String) { get }
}
```
Banner 契约：「设置已保存，部分改动需刷新 Touch Bar 生效」+「立即刷新」按钮（点了调 reloadStandardConfig 后消失）。纯 SwiftUI 组件，挂 Deck 命名空间下（Deck.RefreshBanner）。

### 4.4 domainFields 注册（r60-b 扩展 SettingsSchemaBridge.domainFields）
新注册域的 key 与域标识同名；每个字段必须有 文件:行号 级运行时读者证据，无读者不注册（§5 口径延续）。
