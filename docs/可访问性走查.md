## 人工走查步骤（5 分钟）

1. 打开 VoiceOver：`⌘F5`（或 系统设置 → 辅助功能 → VoiceOver）。
2. 从菜单栏进入「设置」，用 `VO+→` 依次读侧栏：应听到「通用，已选中」「歌词，未选中」等。
3. 进入「编辑器」：读「添加组件」→ 打开组件库 → 读分类与 chip；用 `VO+空格` 添加一个组件。
4. `⌘S` 或读「保存到当前主题」按钮并按下。
5. 回到「关于」→ 读「导出诊断包」并按下 → 出现保存面板（读面板标题即可，取消）。
6. 打开 Mirror（设置 → 通用），`VO+→` 应听到「Touch Bar 镜像」。
