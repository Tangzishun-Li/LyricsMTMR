## 3. 入口与启动路径

**主进程入口**：`MTMR/App/AppDelegate.swift`（@NSApplicationMain，LSUIElement=1 → 菜单栏 app，无 Dock 图标）。

`applicationDidFinishLaunching` 顺序（AppDelegate.swift:29-62）：
1. 测试环境检测（`XCTestConfigurationFilePath` 存在则跳过全部硬件初始化，CI 兼容）
2. AX 辅助功能授权提示（:35）
3. `HapticFeedback.instance.scanAllDeviceIDs()`（:37，触感反馈硬件扫描）
4. `TouchBarController.shared.setupControlStripPresence()`（:38，Control Strip 注册）
5. `TouchBarController.shared.reloadStandardConfig()`（:41，首次加载 items.json）
6. 菜单栏图标 + popover（:44-50，StatusBarMenuView 884 行）
7. `reloadOnDefaultConfigChanged()`（:52，DispatchSource 文件监听 items.json 写事件 → 热重载，:189-205）
8. NSWorkspace 前后台切换通知 → `updateIsBlockedApp`（:54-56，黑名单应用冻结逻辑）
9. `LyricsEngine.shared.start()`（:59，歌词引擎 + MediaRemote）
10. `SlotManager.shared.ensureSlotsDirectory()`（:60）

**退出路径**：`applicationWillTerminate` → `LyricsEngine.shared.shutdown()`（:65）。

## 8. 已知坑位（给后续任务）

1. **目录名末尾有空格**：`/Users/litz/codespace/MTMR with LyricsX /`，shell 脚本引用务必带引号；本工作区（无空格）只放调研文档。
2. **无包管理器**：依赖全部 vendored（Sparkle.framework）；新增依赖需手动拖入工程。
3. **私有 API**：DFRFoundation / MediaRemote / CBBlueLightClient —— 不签名（CODE_SIGNING_ALLOWED=NO）可跑，发布需注意 App Store 不可用（分发走 GitHub Release + Sparkle）。
4. **CI scheme 名**：测试用 `UnitTests`，构建用 `MTMR`（Scheme 名 ≠ target 名）。
5. **run.pl 必须打进 bundle**（MediaRemoteAdapter.swift:37 检查），archive.sh 有 embed 逻辑，勿手动裁剪 Resources。
6. **items.json 是运行时唯一配置**，损坏会导致整条 Touch Bar 重建失败（try! 已改可恢复，但解析错误仍会清空/降级显示）。
7. **测试环境变量**：`XCTestConfigurationFilePath` 存在时跳过 Touch Bar 硬件初始化 —— 本地调试测试勿删。
8. **.secrets.env 是真实密钥文件**（不入库），改代码前先读 .secrets.example.env 模板了解变量名，勿打印值。
