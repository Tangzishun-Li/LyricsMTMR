## 0. 重要前置发现（影响全部 item 的结论）

### 0.1 消费 LyricsMTMR 配置的 app 是 LyricsMTMR fork，不是原版 LyricsX
- 盘点文档称 "LyricsX（歌词应用自带 Touch Bar 支持）" 消费 `LyricsMTMR/items.json` —— **不准确**。
- 实测：`/Applications/LyricsX.app`（bundle id com.JH.LyricsX）二进制中**没有** themeSwitch/fenzhong/showChart/stock 等字符串，
  它只注册原生 NSTouchBar（artwork/playbackControl/lyrics 三件套，见 defaults 的 NSTouchBarConfig）。
- 真正消费 LyricsMTMR 配置的是 **LyricsMTMR fork**（bundle id Toxblh.LyricsMTMR，版本 0.27 build 452，
  `~/Library/Application Support/LyricsMTMR/`），其 dylib 含 ThemeSwitchBarItem / StockBarItem / DeepseekBalanceBarItem / SlotManager 等。
- fork 运行的是 **Debug 构建**（DerivedData 路径，`/Applications/LyricsMTMR.app的替身` 指向它）；
  工作区有 Release 归档（`/LyricsMTMR/Release/LyricsMTMR.xcarchive`，双架构）。
- 建议收尾任务核对：日常到底跑哪个 app、要不要把 fork 换成 Release 包。

### 0.2 双 app 同时运行时存在 Touch Bar 竞态（实测异常）
- MTMR 系统日志实测：`*** Collection <NSConcretePointerArray...> was mutated while being enumerated`
  于 `+[NSFunctionRow markActiveFunctionRowsAsDimmed:]`（AppKit 内部，DFR 状态变化时触发，FAULT 但进程未崩）。
- 即 MTMR 与 LyricsMTMR（以及原版 LyricsX 的 NSTouchBar）同注册 Function Row 时系统内部有竞态，
  表现为 Touch Bar 可能闪烁/异常。**建议明确"同一时刻只跑一个 Touch Bar 应用"**，或做 slot 互斥切换。

### 0.3 盘点文档两处事实错误（需收尾任务修正）
1. LyricsMTMR 索引：实际 [0]=themeSwitch、[1]=dock、[2]=lyrics、[3]=group⇥、[11]=stock sh603568、[12]=stock sz002150
   （文档写 [0]=dock、[1]=lyrics、[10]/[11]=stock，均错位）。
2. **股票名称错误**：sh603568=伟明环保、sz002150=正泰电源（腾讯/东财行情实测确认）。
   文档写"中际旭创"错误 —— 中际旭创是 sz300308。需用户确认想盯的到底是哪两只。
