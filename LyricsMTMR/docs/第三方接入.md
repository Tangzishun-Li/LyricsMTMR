# 第三方接入 · 外部数据写入说明

LyricsMTMR 的本地数据类组件都从同一个目录读取 JSON 文件：

```
~/Library/Application Support/LyricsMTMR/
```

外部程序（记账软件、脚本、快捷指令等）只要把数据**写入/覆盖**对应文件，
Touch Bar 组件就会自动同步显示。组件只读不写（剪贴板历史除外），
不会覆盖你写入的内容。

> 快速打开目录：Finder → `⌘⇧G` → 粘贴上面的路径。

---

## 接入方式总览

| 文件 | 对应组件 | 刷新方式 | 备注 |
| --- | --- | --- | --- |
| `expenses.json` | 消费（expenseTracker） | 每 3 秒检查文件修改时间 | 变化即重载，无需重启 |
| `classes.json` | 课程倒计时（classCountdown） | 跟随 refreshInterval | 支持 dataPath 指向任意路径 |
| `ddls.json` | DDL 列表（ddlList） | 跟随 refreshInterval | 同上 |
| `reading.json` | 阅读进度（readingProgress） | 跟随 refreshInterval | 同上 |
| `subscriptions.json` | 订阅倒计时（subscriptionCountdown） | 跟随 refreshInterval | 同上 |
| `clipboardHistory.json` | 剪贴板历史（clipboardHistory） | 启动时读取 | 字符串数组 |
| `regexRules.json` | 正则速测/正则表 | 打开组件时读取 | 也可在 设置→工具 里编辑/导入 |

---

## 文件格式与示例

### expenses.json · 消费

```json
{
  "expenses": [
    { "amount": 18.5, "category": "餐饮", "date": "2026-08-05" },
    { "amount": 6,    "category": "交通", "date": "2026-08-05" }
  ]
}
```

- `amount`：金额（数字）
- `category`：分类，组件主题 JSON 里 `categories` 可自定义统计口径
- `date`：`YYYY-MM-DD`，组件按当天汇总
- 组件每 3 秒轮询一次文件修改时间，外部写入后**最多 3 秒**自动刷新

命令行追加一笔：

```bash
cd "$HOME/Library/Application Support/LyricsMTMR"
python3 - <<'EOF'
import json, datetime, pathlib
p = pathlib.Path("expenses.json")
data = json.loads(p.read_text()) if p.exists() else {"expenses": []}
data["expenses"].append({
    "amount": 15,
    "category": "餐饮",
    "date": datetime.date.today().isoformat(),
})
p.write_text(json.dumps(data, ensure_ascii=False))
EOF
```

### classes.json · 课程倒计时

```json
{
  "classes": [
    { "name": "高数", "room": "A301", "time": "08:00", "days": [1, 3, 5] },
    { "name": "英语", "room": "B202", "time": "14:00", "days": [1, 2, 3, 4, 5] }
  ]
}
```

- `days`：星期几上课，1 = 周一 … 7 = 周日

### ddls.json · 截止日期

```json
{
  "ddls": [
    { "title": "物理实验报告", "due": "2026-08-10" },
    { "title": "线代作业",     "due": "2026-08-12" }
  ]
}
```

- 48 小时内到期的条目在 Touch Bar 上变珊瑚色告警

### reading.json · 阅读进度

```json
{ "reading": { "title": "三体", "page": 120, "total": 300 } }
```

### subscriptions.json · 订阅续费

```json
{
  "subscriptions": [
    { "name": "Netflix", "price": 60, "renewDate": "2026-08-20" },
    { "name": "iCloud",  "price": 21, "renewDate": "2026-09-01" }
  ]
}
```

- ≤3 天续费的条目会变珊瑚色提醒

### clipboardHistory.json · 剪贴板历史

```json
["第一条内容", "第二条内容", "第三条内容"]
```

- 纯字符串数组；组件启动时读取，之后以应用内记录为准

### regexRules.json · 自定义正则规则

```json
[
  { "name": "手机号", "pattern": "^1[3-9]\\d{9}$" },
  { "name": "邮箱",   "pattern": "^[\\w.+-]+@[\\w-]+\\.[\\w.]+$" }
]
```

- 会追加到 Touch Bar「正则速测 / 正则表」里
- 也可以不碰文件：设置 → 工具 → 正则规则 支持逐条编辑与 JSON 导入

## 用 curl / 脚本把外部数据接进来

通用写法（先写临时文件再原子替换，避免组件读到半个文件）：

```bash
DIR="$HOME/Library/Application Support/LyricsMTMR"
curl -s "https://example.com/api/today" \
  | python3 -c 'import sys,json; ...转成上面的格式...' > "$DIR/.tmp.json" \
  && mv "$DIR/.tmp.json" "$DIR/expenses.json"
```

配合 `crontab -e` 每 5 分钟同步一次：

```cron
*/5 * * * * /path/to/your/sync-script.sh
```

## 示例：把 Outlook / 日历同步到课程倒计时

theme12 的课程倒计时（classCountdown）是**只读轮询**组件：它只按
`refreshInterval` 读取 `classes.json`（或主题里 `dataPath` 指向的文件）
并展示，不会写回日历。所以同步方向永远是「日历 → JSON」。

Outlook 支持导出 ICS 订阅文件（网页版：设置 → 日历 → 共享/导出；
也可以直接拿到日历的 ICS 订阅 URL），下面这个脚本把它转成
`classes.json`：

```python
#!/usr/bin/env python3
"""ics2classes.py — Outlook/苹果日历 ICS → classes.json"""
import json, re, sys
from datetime import datetime
from pathlib import Path

ics = Path(sys.argv[1]).read_text(encoding="utf-8")
events = re.findall(r"BEGIN:VEVENT(.*?)END:VEVENT", ics, re.S)

def field(ev, name):
    m = re.search(name + r"[^:\n]*:(.*)", ev)
    return m.group(1).strip() if m else ""

classes = []
for ev in events:
    start = field(ev, "DTSTART")
    try:
        dt = datetime.strptime(start[:15], "%Y%m%dT%H%M%S")
    except ValueError:
        continue  # 跳过全天事件等无法解析的条目
    classes.append({
        "name": field(ev, "SUMMARY") or "未命名课程",
        "room": field(ev, "LOCATION"),
        "time": dt.strftime("%H:%M"),
        "days": [dt.isoweekday()],  # 1 = 周一 … 7 = 周日
    })

# 按周重复的课程在 ICS 里是多条 VEVENT，按 (名称, 时间, 星期) 去重
seen, unique = set(), []
for c in classes:
    key = (c["name"], c["time"], tuple(c["days"]))
    if key not in seen:
        seen.add(key)
        unique.append(c)

out = Path.home() / "Library/Application Support/LyricsMTMR/classes.json"
tmp = out.with_suffix(".tmp")
tmp.write_text(json.dumps({"classes": unique}, ensure_ascii=False, indent=2))
tmp.replace(out)  # 原子替换，组件不会读到半个文件
print(f"已写入 {len(unique)} 门课 → {out}")
```

如果你的 Outlook 只能导出 CSV（Subject / Start Date / Start Time /
Location 列），把上面的解析换成 `csv.DictReader`，其余逻辑完全一样。

配合 crontab 每天早上自动同步：

```cron
# 每天 07:30 把日历导出转成 classes.json
30 7 * * * /usr/bin/python3 $HOME/scripts/ics2classes.py $HOME/Downloads/outlook.ics
```

写完 JSON 后无需重启 app：组件下一次轮询（refreshInterval）自动读到新数据。

## 自定义文件路径

上述组件在主题 JSON 里都支持 `dataPath` 属性，直接指向你自己的文件，
不占用默认位置：

```json
{ "type": "expenseTracker", "dataPath": "~/Documents/my-ledger/today.json" }
```

## 音量律动的系统音源权限

「音量律动」选择**系统**音源时走 ScreenCaptureKit 采集真实播放音频，
需要授权：系统设置 → 隐私与安全性 → 屏幕录制 → 勾选 MTMR/LyricsMTMR。

- **自动**（默认）：未授权或系统采集无声音时，会自动回落到麦克风，不会卡死。
- **显式选择「系统」**：不会偷偷换成麦克风。未授权时改用内置合成动画兜底
  （律动仍会动，但不是真实音频）；授权后立即恢复真实系统音源。
- 设置 → 工具 里的「回落阻尼」拆成了低频 / 中频 / 高频三个滑杆：
  数值越大，对应频段回落得越慢（更「粘」），修改即时生效，无需重启。
